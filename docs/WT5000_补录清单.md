# WT5000 自动化补录清单（详细版）

> 目标：补齐 `recordings/WT5000/` 的录制文件，使 WT5000 在自动化流程中不再卡在 `Upper_WT_Config` 或“正在解析第N条命令”。

---

## 1. 必须先确认的目录

- 录制根目录：`recordings/WT5000/`
- 建议同时保留：`recordings/WT5000/组件库/`（可选）

请确保所有录制文件都放在 `recordings/WT5000/` 下，命名与下方清单一致。

---

## 2. 最小可用补录（先跑通）

以下 6 个文件优先录制，录完后先验证能否完整执行一轮：

1. `打开WT.json`
2. `打开WT并开始连接.json`
3. `连接WT.json`
4. `点击设定.json`
5. `点击测量.json`
6. `数值详细设置-开始测量.json`
7. `数值详细设置-结束测量.json`

> 说明：第 2 和第 3 可能功能部分重叠，但建议都补齐，方便流程兜底。

## 4. 每个文件录制标准（统一规范）

1. 录制前将 WT5000 窗口最大化。
2. 系统显示缩放固定为 100%（建议）。
3. 分辨率、任务栏位置、双屏布局与实际运行机一致。
4. 每次点击动作间隔 0.2~0.5 秒。
5. 输入框操作尽量包含：点击 -> Ctrl+A -> 输入/粘贴。
6. 弹窗确认动作（确定/确认）必须包含在录制里。
7. 录制完成后做一次回放验证，确认动作命中控件。

---

## 5. 针对“项目设置多选框”的补录重点

你的项目设置是“动态勾选”（由 `config_dict + CELLS_COORD_WT5000` 驱动），
不是固定勾选回放。因此补录时要重点保障以下入口动作可达：

1. 能稳定进入“数值详细设置”窗口。
2. 能切到“项目设置”页签。
3. “项目设置初始化”动作可用（先清空状态）。
4. 可回到“详细设置/文件”页并保存。
5. 最后能点击“确认/应用”。

## 7. 建议补充（可选但推荐）

- 每个关键录制保留一份 `.bak` 备份
- 在 `组件库/` 下放同名副本，便于后续拆分和复用
- 新增一份 `WT5000_录制版本说明.txt`，记录录制环境：
  - Windows 版本
  - 分辨率与缩放
  - WT 软件版本
  - 录制日期与负责人
