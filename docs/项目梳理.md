# 光伏逆变器自动化测试系统 — 项目梳理

> 依据微信交接包（`自动化/交接文档.md`、`通讯命令表.md`、设备手册）与代码仓库 `solarautotestnewui`（**当前维护分支 `dev`**；`V1.1` 为历史 UI/打包基线）整理。  
> 文档目的：用一份说明讲清「这个项目是做什么的、怎么跑起来、核心能力边界在哪」。

---

## 1. 一句话结论

这是一套跑在 **Windows 桌面** 上的 **光伏逆变器合规/特性自动化测试软件**（项目名：`SolarAutoTestDev` / 仓库 `solarautotestnewui`）。

它通过 **SCPI（VISA/TCP）** 和 **Modbus TCP** 控制台架上的交流电源、直流电源、功率分析仪、示波器，按预设试验项目自动下发工况、采集测量数据，完成原先依赖人工联调的标准化测试流程。

**不是** Web 服务，也不是纯数据分析平台；主形态是 **PyQt5 工控上位机**。

---

## 2. 业务背景：解决什么问题

光伏逆变器出厂/认证测试需要反复切换电网侧与直流侧工况，并用功率分析仪记录电压、电流、功率、谐波、闪变等指标。人工操作存在：

- 步骤多、易漏设/漏记
- 多台仪器协议不统一（致茂/爱科 AC、蓝点 DC、横河 WT、DEWETRON、DL850）
- 同一类试验（闪变、谐波、过欠频等）需要可复用、可存档的参数与流程

本项目把这些能力收敛到一个桌面程序里：**选试验 → 配参数 → 连接设备 → 追加/发送指令序列 → 启停采集 → 保存配置与结果**。

交接包中的设备手册对应典型台架硬件：

| 手册 | 对应设备角色 |
|------|----------------|
| `WT3000通讯手册_IM760301-17E.pdf` | 横河功率分析仪通讯参考 |
| `600W/1200W/2400W 可编程电源 DP16(17)用户手册` | 直流/可编程电源侧参考 |

## 3. 系统在台架中的位置

```text
┌─────────────────────────────────────────────────────────┐
│  SolarAutoTest（本软件 / PyQt5）                          │
│  - 设备连接与状态（status.json）                          │
│  - 试验项目参数 UI（Dialog_thai*.py）                     │
│  - 指令编排与发送（SCPITestWave.py）                      │
│  - WTViewer 坐标点击自动化 / DEWETRON XML 配置下发         │
└───────────────┬─────────────────────┬───────────────────┘
                │ SCPI / Modbus TCP   │
     ┌──────────┼──────────┬──────────┼──────────┐
     ▼          ▼          ▼          ▼          ▼
  交流电源   直流电源×1~4  WT3000/     DL850    DEWETRON
 (致茂/爱科) (蓝点等)     WT1800/...  示波器    OXYGEN
                │
                ▼
           被测逆变器（DUT）
```

典型链路：

1. **直流电源** 模拟光伏侧（电压/电流/SAS 曲线等）给逆变器输入  
2. **交流电源** 模拟电网侧（电压、频率、单/三相）  
3. **功率分析仪 / DEWETRON** 测量并记录电气量  
4. **示波器 DL850** 做波形抓取与截图（按需）

## 5. 软件做什么（功能地图）

### 5.1 设备管理

- 连接/断开：交流电源、直流电源 1~4、DL850、WT3000、DEWETRON  
- 资源字符串可为 USB VISA、`IP:端口`（如爱科 `192.168.40.210:8080`、蓝点 `:502`、DEWETRON TCP `10001`）  
- 连接状态写入 **`status.json`**，首页设备卡片据此刷新  
- 重连前必须释放 USBTMC/VISA 句柄（`release_resource_handle`），否则易残留占用  

### 5.2 双协议能力

多数电源控制器同时支持：

- **SCPI**：传统 VISA / SOCKET  
- **Modbus TCP**：爱科 AC、蓝点 DC 等，通过寄存器映射实现与 SCPI 等价操作  

运行时用「是否存在 Modbus client」决定走哪条路径；业务层尽量仍用 SCPI 语义发令。

### 5.3 合规/特性试验项目（已实现一批）

命名上大量带 `Thai` / `thai` 前缀（历史命名，不等同于「仅泰国标准」），对应对话框与 Open/Save 工具对：

| 试验项目 | 典型用途 |
|----------|----------|
| 电压闪变 | 闪变相关工况与测量（常作参考样板；**WT 真机已通过** 2026-08-18） |
| 谐波电流 | 谐波电流测试（**爱科+蓝电国产真机** 2026-09-02） |
| 过载 | 过载能力（**爱科+蓝电国产真机** 2026-09-02） |
| 直流分量 | 直流分量（**爱科+蓝电国产真机** 2026-09-02） |
| 静态 CosPhi / 巴西 CosPhi | 功率因数类 |
| 静态 QU | 静态 Q-U（**WT 已验证**：连续录 `QU_curve`，先升后降台阶） |
| 过频降载 / 过欠频 / 过欠频免疫 / 过欠压-频 | 频率与电压保护相关 |
| 电压保护 10 分钟 | 电压保护 |
| 测试 PU | P-U 相关 |
| 重连 | 并网重连（**爱科+蓝电国产真机** 2026-09-02） |
| 频率适应性 | 频率适应性 |
| 固定 PF | 固定功率因数（**爱科+蓝电国产真机** 2026-09-02 11:39:01） |
| 静态 MPPT | MPPT |

每个项目的共性模式：

1. **对话框**（`Dialog_thai*.py`）填步骤、通道、功率等参数  
2. **Open/Save**（`utils/Open_Save_Thai*.py`）读写本地配置  
3. **Append / Send**（集中在巨型主文件 `SCPITestWave.py`）生成并下发命令序列  
4. 用全局计数器控制「开始/结束试验」按钮是否可点  

### 5.4 功率分析仪两条路线

| 路线 | 说明 |
|------|------|
| **横河 WT 系列** | 程序常通过自动化点击 **WTViewerEfree** 完成「数值详细设置」；坐标定义在 `enums/wt_auto_enums.py`，宏/回放在 `RecPlayer/`。与分辨率、DPI、软件版本强绑定。 |
| **DEWETRON OXYGEN** | TCP SCPI（端口 10001），用 XML 配置 `:SETUP:APPLY`（IEEE 488.2 定长块）。ChannelID 每次加载会变，必须先从设备读映射再改 XML。单客户端连接——远程桌面/本机 Oxygen 会抢连接。 |

### 5.5 V1.1 界面结构

- 主 UI：`ui_files/SCPI_Test.py`（手写，非 pyuic 生成）  
- 布局：左侧可折叠二级菜单 + `QStackedWidget`  
- 页面大致：首页、各设备页、项目配置、命令文件等  
- 首页：设备状态卡片网格 + 当前试验项目卡片  

### 5.6 其它辅助能力

- 斜坡指令 `RampCommand`：电压/频率等逐步变化  
- DEWETRON 配置保存、数据采集页、数值 CSV 导出相关脚本  
- 日志目录 `data_logs/`、命令/配置落盘目录等

## 6. 上位机菜单模块说明

主界面左侧菜单分四块：**首页 → 设备管理 → Auto_Test → 其他**，底部另有刷新按钮。实现以 `ui_files/SCPI_Test.py` 的侧边栏 + `QStackedWidget` 为准，试验子项由 `SCPITestWave.py` 动态挂载。

### 6.1 菜单总览

| 菜单 | 作用 |
|------|------|
| **首页** | 看全局状态（设备是否在线、当前试验） |
| **设备管理** | 单独连接 / 设定每台仪器 |
| **Auto_Test** | 选合规试验项目，配参数并开跑 |
| **其他 → 命令文件** | 浏览已保存的命令 CSV / DEWETRON XML |
| **底部刷新** | 重新扫描 VISA 资源列表 |

推荐操作顺序：

```text
首页看状态
  → 设备管理：逐台连接 AC / DC / WT 或 DEWETRON
  → Auto_Test：选试验 → 填步骤 → 提交/追加
  → 开始试验 → 看日志
  → 需要时到「命令文件」核对已生成的命令/配置
```

### 6.2 首页（页面索引 0）

总览页，不直接发仪器命令。

- **设备状态卡片（2×4）**：交流电源、直流电源 1~4、DL850、WT3000、DEWETRON  
  - 显示绿/红状态点、资源地址、上次连接时间  
  - 数据来自 `status.json`  
  - 点击卡片跳转到对应设备页  
- **当前测试项目卡片**：项目名、状态、进度条、起止时间  

### 6.3 设备管理（页面索引 1~8）

每台仪器一页：选地址 → 连接 → 设定参数 → 查看本页日志。

| 子菜单 | 页面 | 做什么 |
|--------|------|--------|
| **交流电源** | 1 | 模拟电网：电压、频率、单/三相；支持致茂 SCPI、爱科 Modbus 等 |
| **直流电源1** | 2 | 模拟光伏直流侧第 1 路；CV/CC 或 SAS 曲线（如蓝点） |
| **直流电源2** | 3 | 同上，第 2 路 |
| **直流电源3** | 4 | 同上，第 3 路 |
| **直流电源4** | 5 | 同上，第 4 路 |
| **DL850** | 6 | 横河示波器：启停采集、截图等 |
| **WT3000** | 7 | 横河功率分析仪入口（也可走 WT1800/1806E/5000 配置路径）；常配合 WTViewer 自动化 |
| **DEWETRON** | 8 | 德威创 OXYGEN：按 IP 连 TCP SCPI，配 XML、启停采集/录制 |

各页常见操作：连接设备、断开、设定××、本设备返回消息。连接状态会回写 `status.json`，首页同步刷新。

### 6.4 Auto_Test（试验项目，统一进页面索引 9）

点击任一子项都会进入同一 **「项目配置」页**，只切换中间参数面板（`settingStack`）。  
页面包含：该试验步骤 UI、**开始试验 / 结束试验**（及隐藏的暂停/继续）、**操作日志**。  

一般需先在对话框里「提交设定 / 追加」后，「开始试验」才会启用（由各项目 append 计数器控制）。

| 子菜单 | 试验含义（台架侧） |
|--------|-------------------|
| **重连** | 电网故障/掉电后再并网的重连特性（**爱科AC+蓝电DC 国产真机通过** 2026-09-02） |
| **电压闪变** | 闪变相关工况与测量（WT 闪变或 DEWETRON）；常作样板项目（**WT 真机已通过** 2026-08-17 17:44～2026-08-18 08:56） |
| **谐波电流** | 逆变器谐波电流发射/相关测量（**爱科AC+蓝电DC 国产真机通过** 2026-09-02 10:48:55） |
| **固定PF=1** | 固定功率因数（**爱科AC+蓝电DC 国产真机通过** 2026-09-02 11:39:01） |
| **无功能力范围** | P 阶梯 × 极限 cosφ（WT+Chroma 已验；国产台架按总览表稍后） |
| **过载能力测试** | 过载能力（**爱科AC+蓝电DC 国产真机通过** 2026-09-02） |
| **直流分量** | 交流输出直流分量相关（**爱科AC+蓝电DC 国产真机通过** 2026-09-02） |
| **静态QU** | 静态无功–电压（Q-U）特性（**WT 已验证**：一条连续 CSV / `QU_curve`） |
| **Test_PU** | 有功–电压（P-U）特性：改网压，测逆变器有功 P（与静态 QU 同结构：电压 list 连续录 `PU_curve`） |
| **静态Cos(φ)** | 静态功率因数 / cosφ 特性 |
| **Cos(φ)_Brazil** | 巴西标准功率因数相关 |
| **10min过压保护** | 10 分钟平均过压保护 |
| **过频降载** | 电网过频时有功降载 |
| **过欠压_过欠频** | 过/欠压、过/欠频保护与响应（**爱科AC+蓝电DC 国产真机通过** 2026-09-02） |
| **巴西过欠频稳定性** | 巴西过欠频免疫/稳定性（**本次国产台架下一项**，总览序号 9） |
| **静态MPPT测试** | 静态 MPPT（配合直流源曲线）（**本次因默认时长过长暂跳过**） |
| **频率适应性** | 频率适应性（频率变化下的运行能力） |

侧边栏子项与 `comboBox_PS` 文案一一对应，列表见 `SCPITestWave.py` 中 `_auto_sidebar_items` / `SecondProjectSet()`。

### 6.5 其他 → 命令文件（页面索引 10）

管理落盘文件，不是现场连设备。实现见 `DialogFileManager.FileListWidget`。

| Tab | 目录 | 内容 |

## 9. 通讯要点（摘自命令表，便于理解边界）

- **通用 SCPI**：`*IDN?`、`*RST`、`OUTP ON/OFF`、`VOLT`、`FREQ` 等  
- **爱科 AC Modbus**：控制寄存器 `0x0909`，连续控制命令建议间隔约 **2 秒**  
- **蓝点 DC Modbus**：输出开关、SAS/STC 曲线块、`APPLY` 生效寄存器；半连接时首包可能丢，需先刷连接  
- **DEWETRON**：仅 **1** 客户端；`:SETUP:APPLY` 必须用 `#长度位数+长度+XML` 定长块  
- **WT**：业务配置大量依赖 Viewer GUI 自动化，而非纯 SCPI 一条打完  

更全的寄存器与命令见仓库内 `通讯命令表.md`。
