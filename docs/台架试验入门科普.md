# 光伏逆变器自动化试验 · 上班前科普

> 给**还没接触过这个行业**的同事：用大白话讲清「我们在测什么、台架上有哪些设备、那些试验名字是什么意思」。  
> 读完这篇，你再坐到软件前，就不会对「交流源 / 直流源 / 过欠压 / 谐波」完全陌生。

---

## 1. 我们到底在干什么？

家里屋顶、工商业屋顶上的那台「光伏逆变器」，负责把太阳能电池板发出来的**直流电**，变成能并到电网上的**交流电**。

逆变器不能随便并网。电网公司和国家/地区标准会要求它：

- 电压、频率异常时要**保护动作**（该脱网就脱网，该降功率就降功率）
- 并网后发出的电能**质量要合格**（谐波别太大、闪变别晃灯、直流分量别超标……）
- 电网调度下发的有功/无功指令要能**跟得住**
- 光伏光照变化时，要尽量**多发电**（MPPT）

认证实验室 / 厂内测试台架，就是用仪器「假装」出各种电网和光伏工况，把这些能力一条条测出来，并留下可追溯的数据与报告。

**我们的自动化软件（SolarAutoTest）**：把「连仪器 → 设工况 → 启停逆变器相关流程 → 录波存数 →（可选）出分析报告」串成可重复执行的流程，减少人手点仪器、抄数。

## 2. 先建立一张「台架全景图」

把台架想成一台戏：

| 角色 | 现实世界对应 | 台架上用什么「演」 |
|------|--------------|-------------------|
| 太阳 + 电池板 | 给逆变器喂直流电 | **直流源 / 光伏模拟器** |
| 国家电网 | 逆变器并网的交流侧 | **交流源 / 电网模拟器** |
| 被测产品 | 光伏逆变器（DUT） | 真实逆变器样机 |
| 裁判 / 摄像机 | 量测电压电流功率、录波形 | **功率分析仪、德威创等录波设备** |
| 导演 | 按标准走流程、记结果 | **自动化软件 +（可选）IOT 网页开测** |

典型能量方向（简化）：

```text
  直流源(模拟光伏) ──DC──► 逆变器 ──AC──► 交流源(模拟电网)
                              │
                              └── 功率分析仪 / 录波仪「旁路测量」
```

记住两句话就够：

1. **直流侧** = 模拟「太阳有多亮、电池板特性怎样」  
2. **交流侧** = 模拟「电网电压/频率正不正常、要不要调度」

## 3. 直流设备：在演「光伏」

### 3.1 它干什么？

逆变器输入侧要接光伏组件（或组件串）。实验室不可能每次都搬真太阳，所以用**可编程直流源 / 光伏模拟器**：

- 输出一组可调的 **电压–电流（I–V）曲线**
- 常用参数你会在软件里反复看到：

| 缩写 | 中文 | 白话 |
|------|------|------|
| Voc | 开路电压 | 不接负载时电压有多高 |
| Isc | 短路电流 | 短路时电流有多大 |
| Vmp | 最大功率点电压 | 发得最多时对应的电压 |
| Imp | 最大功率点电流 | 发得最多时对应的电流 |
| Pmpp / Pmp | 最大功率 | Vmp × Imp，大概就是「这块板能发多少瓦」 |
| FF | 填充因子 | 曲线「胖瘦」的一种描述，影响仿真真实度 |

功率百分比（如 50%、100%）常表示：**当前直流头寸相对额定有功的比例**，用来模拟阴天/晴天、半载/满载。

### 3.2 你们台架上常见的直流品牌/形态

软件侧会对接多类直流设备（名称以现场接线与软件下拉为准），例如：

- **Chroma** 光伏模拟相关机型  
- **Itech（爱科）** 等可编程源  
- **Bluesight（蓝点）** 等 Modbus 类设备  

试验时常见操作：勾选用几路直流（DC1～DC4）、填 Vmp/Imp 或功率档、等待逆变器启机后再开测。

### 3.3 和「静态 / 动态 MPPT」的关系

- **静态 MPPT**：光照（功率头寸）相对固定，看逆变器能否稳在最大功率点附近。  
- **动态 MPPT**：故意让「光照」按斜坡升上去、降下来，看跟踪是否跟得上（更接近真实云遮）。

## 4. 交流设备：在演「电网」

### 4.1 它干什么？

逆变器交流输出要并到电网。实验室用**可编程交流源 / 电网模拟器**人为制造：

- 正常市电：例如常见试验默认 **230 V / 50 Hz**（现场以规程与铭牌为准，可能是三相或单相）
- 过压、欠压、过频、欠频
- 频率快速变化（ROCOF）、快速电压变化、低电压穿越（LVRT）等

### 4.2 单相 vs 三相（小白必懂）

| | 单相 | 三相 |
|--|------|------|
| 像什么 | 家里常见两根火/零线思路 | 工厂/并网机常见 A/B/C 三相 |
| 软件里 | 选「单相」，通常填一路电压/频率 | 选「三相」，三相电压往往同设或分相设 |
| 接线 | 少 | 多，相位、相序、接错线风险更高 |

**原则**：先问清楚「这台被测机是单相还是三相」，再填交流参数；不要凭感觉抄别的项目。

### 4.3 你们台架上常见的交流品牌

软件会按仪器识别走不同命令，例如：

- **Chroma 61800** 系列（以太网 SCPI 常见）  
- **爱科（Itech）** 等（可能走 SCPI→寄存器/Modbus）  
- 其它通用 SCPI 交流源  

试验开始时常有两段时间概念（名字以软件界面为准）：

| 概念 | 白话 |
|------|------|
| 等待时间 | 交流工况设好后，先稳住、等系统就绪 |
| 启机时间 | 给逆变器上电/并网启动留出的时间，再进入正式测点 |

## 5. 「其它设备」：裁判与摄像机

只调直流/交流还不够——标准要的是**测到了什么**。

### 5.1 功率分析仪（WT 系列等）

横河等 **WT3000 / WT1800 / WT5000** 一类功率分析仪，用来高精度测：

- 电压、电流有效值（Urms / Irms）  
- 有功 P、无功 Q、视在功率 S  
- 功率因数 PF  
- 谐波、不平衡等（按试验勾选测量项）

它可以按设定周期存 CSV/录文件，供事后判定或自动分析出报告。

### 5.2 德威创等录波 / 闪变相关设备

部分试验（尤其**电压闪变**、部分电能质量）会用到德威创一类设备做闪变判定、导出或辅助录波。软件里常有「启用德威创」一类选项——**先在设备页连上，再在试验里选型配置**。

### 5.3 其它你可能听到的设备

| 名称 | 干什么（直觉） |
|------|----------------|
| 示波器 / 高速录波 | 看波形细节、暂态 |
| 负载 / 阻抗网络 | 模拟线路阻抗、特定电能质量条件（视台架配置） |
| 急停 / 安全回路 | 出事一键切断，人身与设备安全优先于任何试验 |

## 6. 试验是什么？——按「考题类型」读名字

下面用「电网在刁难逆变器什么」来理解试验名。不必一次背全，上班后对照软件菜单逐渐熟悉即可。

### 6.1 保护类：电网不正常时，该不该跳、跳得够不够快

| 试验（常见中文名） | 一句话 |
|--------------------|--------|
| **过欠压 / 过欠频（OV/UV、OF/UF）** | 电压或频率越限时，保护是否按规定脱网/动作 |
| **10 分钟过压保护** | 针对「较长时间轻微过压」一类条款的保护验证 |
| **重连** | 故障恢复后，是否按规定延时再并网，而不是立刻抢合 |
| **ROCOF** | 频率变化率过大时的保护（df/dt） |
| **低电压穿越（LVRT）** | 电网电压跌落一段时间，逆变器是否按曲线「扛住」而不是乱跳 |
| **过频降载 / 欠频升载** | 频率高了要减有功、频率低了要加有功（或按标准曲线动作） |
| **巴西过欠频稳定性** 等 | 在频率扫描/特定包络下，看稳定性与免疫能力 |

### 6.2 适应性类：电网在合格范围内「晃一晃」，机器还稳不稳

| 试验 | 一句话 |
|------|--------|
| **电压适应性** | 电压在允许范围内升降，能否持续正常运行 |
| **频率适应性** | 频率在允许范围内变化，能否持续正常运行 |
| **快速电压变化（RVC）** | 电压台阶式快速变化时的响应与录波 |
| **相角突变** | 电网相位突然跳一下时的行为（视项目启用） |

### 6.3 电能质量类：并网后「电干不干净」

| 试验 | 一句话 |
|------|--------|
| **谐波电流** | 输出电流谐波会不会污染电网、是否超标 |
| **电压闪变** | 会不会让灯光闪烁（短时/长时闪变指标） |
| **直流分量** | 交流输出里夹带的直流成分是否超标 |
| **固定 PF=1** | 功率因数固定为 1（纯有功）时的表现与合规性 |

### 6.4 功率控制 / 无功电压类：调度说「加无功、减有功」，跟不跟得住

| 试验 | 一句话 |
|------|--------|
| **过载能力** | 短时超出额定功率的能力与表现 |
| **防逆流** | 不希望往电网倒送电时，控制是否有效 |
| **有功调度** | 按设定的有功功率阶梯限制/调度 |
| **定无功 / 无功注入 / 无功精度 / 无功能力范围** | 无功设定、注入吸收、精度与能力边界 |
| **静态 / 动态 Cosφ（功率因数）** | 按 cosφ 曲线或动态工况控制无功 |
| **静态 / 动态 Q–U（QU）** | 按电压高低自动调无功（电压–无功曲线） |
| **P–U 等** | 有功随电压等条件变化的特性（视标准条款） |

### 6.5 光伏特性类：太阳变了，跟不跟最大功率点

| 试验 | 一句话 |
|------|--------|
| **静态 MPPT** | 相对稳定工况下的最大功率点跟踪 |
| **动态 MPPT** | 光照斜坡变化下的跟踪效率与行为 |

### 6.6 国家标准从哪来？

同一类试验，**巴西 Ordinance 140、意大利 CEI、泰国、南德/VDE、国标** 等条款细节不同（限值、测点、判定、报告格式都可能不同）。  
软件里「国家标准」下拉，本质是：**选哪本考纲来考、以及结案后按哪套分析出报告**。

## 7. 自动化软件里，一天试验大概怎么走？

不必记按钮名，先记流程：

```text
① 确认安全与接线（人）
② 软件连接直流源、交流源、功率分析仪等（设备就绪）
③ 选择试验类型 + 国家标准 + 填交流/直流/时序/录波参数
④ 提交 / 追加到执行队列，自动跑步骤
⑤ 仪器录波、落盘；异常可中止
⑥ （可选）IOT 网页开测、远程看进度；结案后自动分析报告
```

两条工作入口（都会碰到）：

| 入口 | 适合谁 |
|------|--------|
| **工控机桌面软件** | 台架现场连仪器、改参数、看执行日志 |
| **IOT 网页** | 远程选试验、下发任务、看台架状态与报告（任务最终仍落到台架执行） |

## 8. 小白术语速查

| 词 | 白话 |
|----|------|
| DUT | Device Under Test，被测设备，这里就是逆变器 |
| 并网 | 逆变器交流输出接到电网（或电网模拟器） |
| 脱网 / 跳闸 | 保护动作，与电网断开 |
| 有功 P | 「真正做功」的功率，单位常为 W/kW |
| 无功 Q | 不直接做功、但影响电压的功率分量，单位 var/kvar |
| 功率因数 PF / cosφ | 有功与视在功率的关系；1 表示几乎纯有功 |
| 谐波 | 基波以外的频率成分，太多会干扰电网与设备 |
| 闪变 | 电压波动引起的灯光闪烁感 |
| 录波 | 把电压电流等随时间记成文件 |
| SCPI | 仪器常用的文本命令协议（软件对仪器「说话」的一种方式） |
| handoff | 网页/远程任务交给桌面软件接着跑的一种交接 |

## 9. 上班前建议你搞清楚的 8 个问题

到岗第一天，不妨主动问师傅或对照现场铭牌弄清：

1. 今天被测逆变器是**单相还是三相**？额定电压/频率/功率是多少？  
2. 直流接了**几路**？常用 Vmp/Imp 或功率档怎么取？  
3. 交流源、直流源、功率分析仪**分别是哪几个品牌型号**？IP/串口在哪看？  
4. 急停按钮在哪？异常时**先按什么**？  
5. 今天要跑的试验属于：保护 / 电能质量 / 功率控制 / MPPT 里的哪一类？  
6. 执行的是**哪国/哪本标准**？  
7. 数据文件保存在哪？谁负责看判定或出报告？  
8. 出问题是找台架硬件、还是软件参数、还是标准理解——**升级路径找谁**？

## 10. 一句话收束

- **直流设备** = 假太阳（喂逆变器输入）  
- **交流设备** = 假电网（接逆变器输出、制造各种电网刁难）  
- **分析仪 / 录波** = 裁判与录像  
- **试验名称** = 考纲上的一道道题（保护、质量、调度、跟踪……）  
- **我们的自动化** = 让这些题可以稳定、可重复地考，并留下证据
