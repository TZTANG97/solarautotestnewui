### 2.2 爱科（Itech）Modbus 寄存器

| 寄存器地址 | 名称 | 说明 | 值 |
|-----------|------|------|-----|
| `0x0909` | REG_CONTROL | 开关机控制 | 见下方控制命令 |
| `0x090B` | REG_SAVE_PARAM | 保存参数 | `0x0001` = 保存 |
| `0x0C48` | REG_PHASE_MODE | 相位模式 | `0x0001` = 三相联动, `0x0002` = 独立(含单) |
| `0x0C00` | REG_VOLT_A | A相电压 | 值×100 = 实际电压 |
| `0x0C02` | REG_VOLT_B | B相电压 | 值×100 = 实际电压 |
| `0x0C04` | REG_VOLT_C | C相电压 | 值×100 = 实际电压 |
| `0x0C0F` | REG_FREQ | 频率 | 值×1000 = 实际频率 |

#### 控制命令值（REG_CONTROL）

| 值 | 命令 | 说明 |
|----|------|------|
| `0x0001` | CMD_OFF | 关机 |
| `0x0002` | CMD_ON | 开机 |
| `0x0003` | CMD_RUN | 运行 |
| `0x0004` | CMD_STANDBY | 待机 |
| `0x0005` | CMD_DISCHARGE | 放电 |
| `0x0007` | CMD_RESET | 复位 |
| `0x0008` | CMD_OUTPUT_ON | 输出吸合 |
| `0x0009` | CMD_OUTPUT_OFF | 输出断开 |
| `0x0014` | CMD_QUERY_STATUS | 查询状态信息 |

#### SCPI → Modbus 映射

| SCPI 命令 | Modbus 操作 |
|-----------|-------------|
| `*RST` | FC06 `0x0909` = `0x0007` |
| `OUTP ON` | FC06 `0x0909` = `0x0008` |
| `OUTP OFF` | FC06 `0x0909` = `0x0009` |
| `SYST:RUN` | FC06 `0x0909` = `0x0003` |
| `SYST:STANDBY` | FC06 `0x0909` = `0x0004` |
| `INST:PHASE SINGLE` | FC06 `0x0C48` = `0x0002` |
| `VOLT <val>` | FC10 `0x0C00/02/04` = `[0x0000, val×100]` |
| `FREQ <val>` | FC10 `0x0C0F` = `[0x0000, val×1000]` |
| `SYST:SAVE` | FC06 `0x090B` = `0x0001` |

| 寄存器地址 | 名称 | 说明 | 值 |
|-----------|------|------|-----|
| `0x0BB8` | REG_OUTP | 输出开关 | `0x00AA` = ON, `0x0055` = OFF |
| `0x0F95` | REG_OUTPUT_MODE | 工作模式 | `0x0000` = 原载, `0x0001` = SAS, `0x0002` = 电池模拟器 |
| `0x0FA9` | REG_ORIG_SUBMODE | 原载子模式 | `0x0000` = CV, `0x0001` = CC, `0x0002` = CP, `0x0003` = CR |
| `0x0FAA` | REG_ORIG_PARAM | 原载参数块 | CV 模式 (4 字) |
| `0x0FAE` | REG_ORIG_CC_PARAM | CC 参数块 | CC 模式 (2 字) |
| `0x0FB0` | REG_ORIG_CP_PARAM | CP 参数块 | CP 模式 (2 字) |
| `0x0FB2` | REG_ORIG_CR_PARAM | CR 参数块 | CR 模式 (2 字) |
| `0x1B61` | REG_CURVE_BLOCK | STC 曲线块 | 9 字数据 |
| `0x1B75` | REG_APPLY | 应用生效 | `0x0055` = 触发 |

#### 蓝点 IDN 寄存器

| 寄存器地址 | 数量 | 说明 |
|-----------|------|------|
| `0x09D3` | 8 | 型号字符串（主地址） |
| `0x104C` | 8 | 型号字符串（备用地址） |
| `0x0A15` | 75 | 固件版本字符串 |

#### STC 曲线块结构（0x1B61 起，9 字）

| 偏移 | 名称 | 说明 | 单位 |
|------|------|------|------|
| 0 | custom_mode | 自定义模式 | - |
| 1 | pmpp_stc_kw | 最大功率 | W (值÷1000) |
| 2 | reserved | 保留 | - |
| 3 | umpp_stc_v | 最大功率点电压 | V (值÷100) |
| 4 | reserved | 保留 | - |
| 5 | irradiance_wm2 | 辐照度 | W/m² (值÷10) |
| 6 | temp_c | 温度 | ℃ (值÷10) |
| 7 | flags_word | 标志字 | - |
| 8 | fill_factor | 填充因子 | - (值÷1000) |


## 七、Modbus TCP 功能码

### 7.1 功能码说明

| 功能码 | 名称 | 说明 |
|--------|------|------|
| `0x03` | FC03 | 读保持寄存器 |
| `0x04` | FC04 | 读输入寄存器 |
| `0x06` | FC06 | 写单个寄存器 |
| `0x10` | FC16 | 写多个寄存器 |

### 7.2 帧格式

#### FC06 写单寄存器

```
设备ID + 0x06 + 地址(2字节) + 值(2字节) + CRC(2字节)
```

#### FC10 写多寄存器

```
设备ID + 0x10 + 起始地址(2字节) + 数量(2字节) + 字节数 + 值(多字节) + CRC(2字节)
```

## 八、命令使用示例

### 8.1 交流电源连接并设置

```python
# SCPI 路径
handle.write('INST:PHASE THREE')    # 三相模式
handle.write('INST:EDIT EACH')      # 单相编辑
handle.write('INST:NSEL 1')         # 选择A相
handle.write('VOLT 220')            # 设置电压220V
handle.write('FREQ 50')             # 设置频率50Hz
handle.write('SYST:RUN')            # 运行
handle.write('OUTP ON')             # 输出吸合

# Modbus 路径（爱科）
client.write_register(0x0C48, 0x0002)  # 单相独立模式
client.write_registers(0x0C00, [0x0000, 22000])  # A相电压220V
client.write_registers(0x0C0F, [0x0000, 50000])  # 频率50Hz
client.write_register(0x0909, 0x0003)  # 运行
client.write_register(0x0909, 0x0008)  # 输出吸合
```

### 8.2 直流电源设置（蓝点）

```python
# SCPI 路径
handle.write('VOLT 500')
handle.write('CURR 10')
handle.write('OUTP ON')

# Modbus 路径（蓝点）
client.write_register(0x0F95, 0x0001)  # SAS 模式
client.write_registers(0x1B61, curve_words)  # 写入STC曲线
client.write_register(0x1B75, 0x0055)  # 应用生效
client.write_register(0x0BB8, 0x00AA)  # 输出ON
```

### 8.3 DEWETRON 配置应用

```python
# 读取当前配置
xml = handle.query(':SETUP:READ?')

# 修改配置后应用
xml_len = len(xml.encode('utf-8'))
num_digits = len(str(xml_len))
cmd = f":SETUP:APPLY #{num_digits}{xml_len}" + xml
handle.write(cmd)
```

## 九、注意事项

1. **DEWETRON 连接限制**：只允许 1 个客户端连接，远程桌面会阻断 VISA 连接
2. **爱科 AC 命令间隔**：连续两条控制命令需间隔 2 秒，否则后一条会覆盖前一条
3. **蓝点 DC 输出前**：TCP 半连接时第一条命令可能丢失，需先刷新连接
4. **ChannelID 动态分配**：DEWETRON 每次加载配置后 ChannelID 会重新生成
5. **IEEE 488.2 格式**：`:SETUP:APPLY` 必须使用定长块格式，不能用引号包裹
6. **Modbus 站号**：所有设备默认站号为 1
