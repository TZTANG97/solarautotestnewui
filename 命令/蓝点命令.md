# 蓝点直流 — SCPI / API 与 Modbus 对照（`BluesightTranslator`）

依据项目内 **`BluesightTranslator`**（`scpi_to_modbustcp.py`）、**`Dialog_Bluesight_DC_Setting.py`**、**`devices/dc_controller.py`** 当前实现整理；原载四类参数顺序与数值编码已与上位机抓包对齐。

**约定**

- 传输：**Modbus TCP**，默认站号 **`device_id = 1`**（pymodbus 亦兼容 `slave=`）。
- **FC06**：功能码 **0x06**，写单个保持寄存器。
- **FC16**：功能码 **0x10**，写多个保持寄存器（本文档统称 FC16；部分资料写作 **10H**）。
- 曲线块、模式切换等写入后常跟 **`REG_APPLY`** 触发落地；**原载四类参数下发不使用 APPLY**（与抓包一致）。

---

## 1. 寄存器地址汇总（十六进制）

| 符号常量 | 地址 | 说明 |
| -------- | ---- | ---- |
| `REG_OUTP` | **0x0BB8** | 输出吸合/断开命令字 |
| `REG_OUTPUT_MODE` | **0x0F95** | 输出工作模式：0=原载，1=SAS，2=电池模拟器 |
| `REG_APPLY` | **0x1B75** | 写入 **`VAL_APPLY=0x0055`** 触发参数生效（曲线、SYST:MODE、Vmp/Pmp/FF 等） |
| `REG_CURVE_BLOCK_START` | **0x1B61** | SAS 曲线块起始，连续 **9** 个保持寄存器 |
| `REG_ORIG_SUBMODE` | **0x0FA9** | 原载子模式：0=恒压，1=恒流，2=恒功率，3=恒阻 |
| `REG_ORIG_PARAM_BLOCK_START` | **0x0FAA** | 原载 **恒压** 参数块起始，连续 **4** 字 |
| `REG_ORIG_CC_PARAM_START` | **0x0FAE** | 原载 **恒流** 参数起始，连续 **2** 字 |
| `REG_ORIG_CP_PARAM_START` | **0x0FB0** | 原载 **恒功率** 参数起始，连续 **2** 字 |
| `REG_ORIG_CR_PARAM_START` | **0x0FB2** | 原载 **恒阻** 参数起始，连续 **2** 字 |
| `REG_IDN_MODEL` | **0x09D3** | `*IDN?` 型号串（优先 **FC04** 输入寄存器，8 字） |
| `REG_IDN_MODEL_ALT` | **0x104C** | 型号串备用起始地址 |
| `REG_FW_STRING_BLOCK` | **0x0A15** | 固件/版本类字符串块（**FC04**，长度 `0x4B`） |

**离散 SAS 参数（`translate` 映射）**

| 符号含义 | 地址 | 写入形态 |
| -------- | ---- | -------- |
| `Pmp` | **0x1B62** | 32 位：`[低16, 高16]`，标幺见下节 |
| `Vmp` | **0x1B64** | 32 位：`[低16, 高16]` |
| `FF` | **0x1B69** | 单寄存器 16 位 |

---

## 2. 输出控制 `REG_OUTP`（0x0BB8）

| 含义 | 写入值 |
| ---- | ------ |
| 输出 ON | **0x00AA** |
| 输出 OFF | **0x0055** |

**Modbus**：**FC06**，`addr=0x0BB8`，`value` 见上表。

**脚本侧**：Modbus 连接时 **`DCController`** 仅写该寄存器，**不对 `ModbusVISA` 发送 SCPI `OUTP ON/OFF`**（见 `dc_controller.py`）。

---

## 3. `SYST:MODE` — 工作模式（原载 / SAS / 电池模拟器）

写 **`REG_OUTPUT_MODE`（0x0F95）** 后，再 **FC06** **`REG_APPLY`（0x1B75）= `VAL_APPLY`（0x0055）**。

| 写入值 | 含义 | 文本参数示例 |
| ------ | ---- | -------------- |
| **0x0000** | 原载 | `SYST:MODE 0`、`原载`、`ORIG`… |
| **0x0001** | SAS | `1`、`SAS` |
| **0x0002** | 电池模拟器 | `2`、`电池模拟器`、`BAT`… |

---

## 4. SAS 曲线块（`0x1B61` 起连续 9 字）与 `BluesightCurveSTC`

由 **`BluesightTranslator.build_curve_words(stc)`** 生成 9 个 `uint16`，再通过 **`write_curve_block`**：**FC16** 写 **`0x1B61` 连续 9 字**，默认再 **APPLY**。

| 索引 | 含义 | 换算（与代码一致） |
| ---- | ---- | ------------------ |
| [0] | `custom_mode` | 默认 `0x0002` |
| [1] | Pmpp STC | `int(Pmpp_kW * 1000)` |
| [2] | 保留 | **0** |
| [3] | Umpp STC | `int(Umpp_V * 100)` |
| [4] | 保留 | **0** |
| [5] | 辐照度 | `int(W/m2 * 10)` |
| [6] | 温度 | `int(摄氏度 * 10)` |
| [7] | `flags_word` | 默认 `0x0001` |
| [8] | 填充因子 FF | `int(FF * 1000)`（如 0.8 对应 800） |

`fill_factor` 合法范围 **0.25～0.95**（`BluesightCurveSTC.validate`）。

---

## 5. `translate()` 支持的 SCPI 与换算

对 **`command_map`** 中的指令：**FC06** 或 **FC16**（32 位项为连续 2 字）。**`Vmp` / `Pmp` / `FF`** 成功后额外 **APPLY**。

| 指令 | 寄存器 | 换算 |
| ---- | ------ | ---- |
| `OUTP ON` / `OUTP OFF` | 0x0BB8 | 见第 2 节 |
| `Vmp` | 0x1B64 | `value_V * 100` 后 32 位写入 |
| `Pmp` | 0x1B62 | `value_kW * 1000` 后 32 位写入 |
| `FF` | 0x1B69 | 浮点 0～1 时乘 1000，否则按整数 |
| `APPLY` | 0x1B75 | 固定 **0x0055** |

未列入指令返回错误；**曲线下发**请调用 **`write_curve_block(...)`**，不用裸 SCPI。

其它：**`*CLS` / `*RST`** 视为 noop；**`*IDN?`** 见第 7 节。

## 6. 原载四类：参数编码与 Modbus 顺序（抓包对齐）

子模式寄存器均为 **`REG_ORIG_SUBMODE`（0x0FA9）**：**CV=0，CC=1，CP=2，CR=3**。

### 6.1 恒压（CV）

1. **FC06** `0x0FA9` = **0**
2. **FC16** `0x0FAA` 连续 **4** 字：`[U*100, 0, R内*100, 0]`（电压、内阻分辨率 0.01）

### 6.2 恒流（CC）

1. **FC16** `0x0FAE` **2** 字：`[I*100, 0]`（例：20 A 为 `0x07D0 0x0000`）
2. **FC06** `0x0FA9` = **1**

### 6.3 恒功率（CP）

1. **FC06** `0x0FA9` = **2**
2. **FC16** `0x0FB0` **2** 字：`[P_kW*1000, 0]`（工程上限 **30 kW**）

**程序内约束**：功率 **`ORIG_CP_MAX_KW = 30.0`**；界面 **`Dialog_Bluesight_DC_Setting`** 恒功率输入范围为 **0～30 kW**。

### 6.4 恒阻（CR）

1. **FC16** `0x0FB2` **2** 字：`[R负载*100, 0]`（例：2 欧为 `0x00C8 0x0000`）
2. **FC06** `0x0FA9` = **3**

**顺序**：**CV / CP** 为先子模式再参数；**CC / CR** 为先参数再子模式。

**Python**：统一入口 **`BluesightTranslator.write_original_load_params(func_index, ...)`**（`func_index` 为 0～3）。

---

## 7. `*IDN?`

依次尝试：**FC04** `0x09D3`×8 → **FC03** 同址 → **FC04** 备用 **`0x104C`**×8；型号为寄存器高低字节拼 ASCII。可选再读 **FC04** `0x0A15`×`0x4B` 拼固件串。
