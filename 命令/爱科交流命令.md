# 爱科交流电源 — SCPI 与 Modbus 对照（`ItechTranslator`）

依据项目内 `**ItechTranslator**`（`test_guochan.py` / `scpi_to_modbustcp.py`）当前实现整理，对应脚本 **275–311 行** 使用的命令及注释中的示例。

**约定**

- 传输：**Modbus TCP**，默认 `device_id = 1`。
- **FC06**：功能码 0x06，写单个保持寄存器。
- **FC10**：功能码 0x10，写多个保持寄存器（本项目中多为连续 **2 个寄存器**：`[0x0000, 数据字]`）。
- 电压：`寄存器数据字 = int(电压V × 100)`，分辨率 **0.01 V**。
- 频率：`寄存器数据字 = int(频率Hz × 1000)`，分辨率 **0.001 Hz**。
- `**auto_save = True`** 时，电压/频率等参数写入成功后，会再执行一次 **保存参数**（见第 4 节）。

## 1. 寄存器地址汇总（十六进制）


| 符号常量             | 地址         | 说明                           |
| ---------------- | ---------- | ---------------------------- |
| `REG_CONTROL`    | **0x0909** | 开关机与运行控制命令字                  |
| `REG_SAVE_PARAM` | **0x090B** | 保存参数                         |
| `REG_PHASE_MODE` | **0x0C48** | 相位编辑模式（`INST:EDIT EACH` 时写入） |
| `REG_VOLT_A`     | **0x0C00** | A 相电压（起始地址，写 2 个寄存器）         |
| `REG_VOLT_B`     | **0x0C02** | B 相电压                        |
| `REG_VOLT_C`     | **0x0C04** | C 相电压                        |
| `REG_FREQ`       | **0x0C0F** | 频率（起始地址，写 2 个寄存器）            |

## 2. 控制寄存器 0x0909 命令值（`_send_control` → FC06）


| 含义   | 常量名                | 写入值（value） |
| ---- | ------------------ | ---------- |
| 关机   | `CMD_OFF`          | **0x0001** |
| 开机   | `CMD_ON`           | **0x0002** |
| 运行   | `CMD_RUN`          | **0x0003** |
| 待机   | `CMD_STANDBY`      | **0x0004** |
| 放电   | `CMD_DISCHARGE`    | **0x0005** |
| 复位   | `CMD_RESET`        | **0x0007** |
| 输出吸合 | `CMD_OUTPUT_ON`    | **0x0008** |
| 输出断开 | `CMD_OUTPUT_OFF`   | **0x0009** |
| 查询状态 | `CMD_QUERY_STATUS` | **0x0014** |


**Modbus 操作**：`FC06`，`addr=0x0909`，`value` 见上表。

## 3. `test_guochan.py` 第 275–311 行相关：原始 SCPI → 代码行为 / Modbus

### 3.1 注释中的系统与输出命令


| 原始 SCPI          | 代码侧转换结果  | 寄存器与写入值                 |
| ---------------- | -------- | ----------------------- |
| `SYST:POWER ON`  | FC06 写控制 | **0x0909** = **0x0002** |
| `SYST:RUN`       | FC06 写控制 | **0x0909** = **0x0003** |
| `SYST:STANDBY`   | FC06 写控制 | **0x0909** = **0x0004** |
| `OUTP ON`        | FC06 写控制 | **0x0909** = **0x0008** |
| `OUTP OFF`       | FC06 写控制 | **0x0909** = **0x0009** |
| `SYST:POWER OFF` | FC06 写控制 | **0x0909** = **0x0001** |


### 3.2 模式、相位、编辑方式


| 原始 SCPI             | 代码侧转换结果                                            | 寄存器与写入值                                   |
| ------------------- | -------------------------------------------------- | ----------------------------------------- |
| `INST:PHASE THREE`  | 仅设置内部状态 `phase_mode=THREE`，不访问 Modbus              | —                                         |
| `INST:PHASE SINGLE` | 设置 `phase_mode=SINGLE`、`edit_mode=EACH`，不访问 Modbus | —                                         |
| `INST:NSEL 3`       | 仅设置 `current_phase=3`（影响后续 `VOLT` 目标相）             | —                                         |
| `INST:EDIT EACH`    | 写相位模式寄存器，并设 `edit_mode=EACH`                       | **0x0C48** = **0x0002**（`write_register`） |
| `INST:EDIT ALL`     | 单相模式时返回失败；否则只设 `edit_mode=ALL`，不写 0x0C48           | 见代码分支                                     |


### 3.3 电压 `VOLT`（与 `phase_mode` / `edit_mode` / `current_phase` 相关）

- **三相 + 多相编辑**（`THREE` 且 `ALL`）：对 **0x0C00 / 0x0C02 / 0x0C04** 各执行一次 **FC10**（两寄存器数据相同）。
- **否则**（单相模式，或 `EACH`）：只对 **当前相** 写 **FC10**；相别由 `INST:NSEL` 决定（1→A，2→B，3→C）。

按你当前脚本顺序：`INST:PHASE SINGLE` → `INST:NSEL 3` → `INST:EDIT EACH` → `VOLT 200`  
结果：电压写在 **C 相**，`200 × 100 = 20000 = 0x4E20`。


| 原始 SCPI             | 代码侧转换结果                                    | 寄存器与写入值              |
| ------------------- | ------------------------------------------ | -------------------- |
| `VOLT 200`（当前脚本上下文） | FC10，`quantity=2`，`words=[0x0000, 0x4E20]` | 起始地址 **0x0C04**（C 相） |


未调用 `INST:NSEL` 时默认 `current_phase=1`，对应起始地址 **0x0C00**（A 相）。

### 3.4 频率 `FREQ`（脚本中为注释）


| 原始 SCPI     | 代码侧转换结果                           | 寄存器与写入值                                |
| ----------- | --------------------------------- | -------------------------------------- |
| `FREQ 49.9` | FC10，频率 ×1000 → 49900（**0xC2EC**） | 起始 **0x0C0F**，`words=[0x0000, 0xC2EC]` |

## 4. 保存参数（`auto_save` 为 True）


| 触发                                      | Modbus | 寄存器与写入值                 |
| --------------------------------------- | ------ | ----------------------- |
| `_set_voltage_`* 或 `_set_frequency` 成功后 | FC06   | **0x090B** = **0x0001** |
| 显式 `SYST:SAVE`                          | FC06   | **0x090B** = **0x0001** |


因此在本脚本场景下，一次成功的 `VOLT 200` 通常包含：**FC10（0x0C04）** + **FC06（0x090B）**。

## 5. 返回的 `assembled` 字符串格式（便于对照抓包）

成功写出寄存器时，`translate` 返回列表中会包含类似：

- `FC06 写单寄存器 addr=0xXXXX value=0xXXXX device_id=1 | PDU(hex)=...`
- `FC10 写多寄存器 addr=0xXXXX quantity=2 words=[0x0000,0xXXXX] device_id=1 | PDU(hex)=...`
