========================================
  评论采集数据分类工具 — 使用说明
========================================

【需要什么】
  - Windows
  - Python 3.10+（首次请安装，勾选 Add to PATH）
    https://www.python.org/downloads/

【怎么用（任选一种）】

  方式1（推荐）：把「采集数据.xlsx」拖到「运行分类.bat」上松开

  方式2：双击「运行分类.bat」，在弹窗里选 Excel

  方式3：命令行
      python classify_comments.py 采集数据.xlsx

【换电脑】
  把整个 comment_classify 文件夹拷过去即可。
  第一次运行会自动 pip 安装 pandas、openpyxl。

【输出】
  与原文件同目录生成：采集数据_分类结果.xlsx
  内含：分类汇总 / 全量标注 / 求职相关明细 / 按主题分表 / IP交叉

【要求 Excel 列】
  至少包含：评论内容、评论者IP地址、笔记标题
  （评论者昵称、点赞数等可选，有则一并导出）
